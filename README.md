## 📦 NuGet Packages

### [KZ.FileHash](https://www.nuget.org/packages/KZ.FileHash)

A lightweight .NET library for calculating cryptographic hashes of files and streams asynchronously.

Designed for applications that need reliable file hashing while keeping memory usage controlled.

Key capabilities include:

* Multiple hashing algorithms
* Asynchronous processing
* Progress reporting
* Cancellation support
* File and stream processing
* Support for non-seekable streams

## 🌟 Featured Project

### [File Hash Generator & Validator](https://github.com/Kareem-Zein/FileHashGeneratorAndValidator)

A lightweight open-source desktop application for generating and validating file hashes locally.

The application uses **[KZ.FileHash](https://www.nuget.org/packages/KZ.FileHash)** as its reusable hashing core.

Key characteristics:

* Local and offline file hashing
* Hash generation and validation
* Multiple hashing algorithms
* Chunked stream processing
* Controlled memory usage
* Responsive WPF desktop interface
* Self-contained distribution

The application is built with **WPF-UI** and provides a modern Windows-inspired interface without requiring a pre-installed .NET runtime when distributed as a self-contained executable.
